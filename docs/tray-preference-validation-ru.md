# Переключатель значка и фон Mac — 26 октября 2026 года

Согласованный переключатель из макета v45 перенесён в общие настройки Slint. Для прежних настроек он включён по умолчанию, изменения сохраняются автоматически. На Mac: **Показывать значок в строке меню**, на Windows: **Показывать значок в трее**. Он управляет только этим значком; Dock Mac и фоновые загрузки остаются доступны. Управление и пояснения включены во все четырнадцать языковых каталогов.

## Реализация и регрессии

Значок Mac теперь использует независимый нативный `NSStatusItem`, удерживаемый обработчик действий и одно стабильное `NSMenu`, принадлежащие платформенной оболочке. Скорости и счётчики обновляют существующие пункты меню. Скрытие основного окна не уничтожает владельца. Явное выключение и выход удаляют значок; включение создаёт одного владельца с актуальными языком и статистикой. Дополнительный периодический опрос для восстановления не добавлен. Брендовый SVG растеризуется в 36 пикселей для значка размером 18 пунктов на Retina.

Это платформенное решение, проверенное в сценарии наблюдавшегося сбоя. Точный источник сбоя внутри Slint не установлен. Windows сохраняет реализацию трея Slint и получает **Файл → Выйти**, чтобы выход оставался доступен при отключённом значке; повторный запуск возвращает окно через существующий механизм единственного экземпляра. Прототип интерфейса AppKit не менялся.

Тесты покрывают включение по умолчанию для старых/частичных настроек, сохранение false, настоящие UI-сохранение/откат/фокус, сохранение false при других изменениях и пробуждение скрытого UI при изменении настройки без пробуждения от скоростей при отключённом значке. Обзор обнаружил, что повреждённая/будущая сессия мешала прочитать корректные настройки: теперь настройки читаются первыми; регрессия проверяет выключенный значок и сохранность исходных байтов обоих файлов. Нативный lifecycle probe проверяет отложенное создание, выключение/включение, скрытие, завершение, делегат и скрытый цикл событий. Callback выхода Windows проверен при полной очереди и повторной команде.

## Физическая проверка Mac

Использованы только собственная `FlowTorrentTrayPreferenceAudit.app` и фикстура `/private/tmp/flowtorrent-tray-preference-20261026` на Apple Silicon, macOS 27.0.1 (26A434). Установленное приложение, пользовательские торренты и изменённый основной checkout сохранены. В пакете настоящий Mach-O executable с локальной ad-hoc подписью; это тестовый стенд, не установщик и не подписанный релиз.

- В нативных настройках проверены выключение/включение, сохранение фокуса и точные JSON false/true. Светлый русский интерфейс Retina: локальный `target/slint-tray-preference-20261026/native-settings-light-ru.png`.
- Полное окно закрыто во время ограниченной по скорости локальной загрузки 16 МиБ. Автор подтвердил: верхний значок остался и меню работает. Ранее именно в этом сценарии значок пропадал.
- Скрытая загрузка завершилась; все 16 777 216 байт совпали с источником. SHA-256: `3f5acf06f1ec4128a69d246cec655c8d82ceb48b98df79e4ba69affafd80c146`. После этого фикстура остановлена для проверок жизненного цикла.

После последнего перезапуска и повторного скрытия автор ещё раз подтвердил: значок остался, пункт «Открыть FlowTorrent» вернул окно. Перезапуск с сохранённой настройкой и итоговые локальные проверки записаны ниже. Ограниченная проверка Mac не подтверждает ночную стабильность, физический Intel, отображение трея/DPI Windows или все версии ОС. Межплатформенный CI и оставшаяся физическая матрица релиза — отдельные доказательства. Этот отчёт не разрешает релиз, теги или загрузку установщиков.

## Локальная сборка

Оптимизированная ARM-сборка упакована в локальную `target/local-macos/slint-tray-preference-20261026-5fe87cb/FlowTorrent.app` (около 38 МиБ на диске), с лицензиями для целевой платформы, проверенными по неизменённому lockfile. Строгая проверка ad-hoc подписи прошла. Упаковка сохраняет документированное исключение strip для host-зависимостей на macOS 27; это не доказывает работу обычной команды `cargo build --release` без исключения на этой ОС. Установленная копия не заменена; DMG/установщик/релиз не загружались.
