# Эксперимент выбора файлов

Одобрено 31.10.2026 только для `experiments/file-priorities`. Это явное экспериментальное расширение спецификации 1.0, не изменение релизного объёма main.

Этап 1: чекбоксы файлов в сведениях об одном торренте. Изменения применяются сразу, сохраняются в манифесте до подтверждения, оставляют данные на диске и прежнее намерение «запущен/остановлен». Актор применяет отдельные переключения к актуальному манифесту, а не устаревшему списку UI. Во время проверки, ошибки или незавершённого переноса в Корзину изменения запрещены.

После добавления можно отключить всё: статус «Файлы не выбраны», нулевой прогресс выбранных данных, без уведомления о завершении. Новое добавление требует хотя бы один файл. Выбор сохраняется при восстановлении; запуск разрешён только после проверки. Версия манифеста 2 допускает пустой выбор; версия 1 читается без изменений и обновляется только при изменении выбора. Старые клиенты должны отклонить версию 2, сохранив файл.

librqbit 9.0.1 поддерживает `Session::update_only_files`. Меняем выбор на остановленном торренте, затем запускаем только при сохранённом намерении Active. При ошибке сохранения остаётся прежний выбор. При ошибке движка после сохранения торрент остаётся остановленным с понятной ошибкой; повтор восстанавливает сохранённый выбор. Устаревший выбор не запускаем. Уведомление о завершении остаётся однократным на торрент, флаг не сбрасываем.

Доступ к данным остаётся через закреплённые дескрипторы с проверками путей. Отключение не удаляет и не обрезает данные; пограничные куски могут содержать байты отключённого файла. Корзина обрабатывает принадлежащие приложению файлы, включая отключённые после скачивания, с прежними проверками идентичности и жёстких ссылок. Удаление из списка сохраняет данные.

Этап 2: настоящие приоритеты Low/Normal/High, сохранение и тесты через отдельно проверяемый патч librqbit. В этап 1 не входит. Требуется совместимость исходников Windows/Mac; локальная проверка Mac не доказывает работу Windows/Intel. AppKit-прототип, другие эксперименты и main не меняются.

Этап 2 теперь реализован отдельно: [поведение приоритетов](file-priorities-experiment-ru.md), [локальная проверка](../validation/file-priorities-stage2-2026-11-01-ru.md). Изменение приоритета переводит данные в v3; выбор файлов первого этапа сохраняет эту версию.
