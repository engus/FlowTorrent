# Approved unslop polish

The maintainer approved the three before/after web studies on 2 November 2026 and requested their transfer to Slint while retaining every existing function and behavior. The implementation starts at `10d647b`, including file/torrent priorities and the direct-callback guards; main, AppKit and other experiments are not edited.

Use existing Nunito, supplied brand geometry and pinned Lucide assets. Keep white/neutral surfaces, a restrained teal accent, clear semantic transfer states, sentence-case headings, tabular/aligned values and visible keyboard focus. Core spacing is 4/8/12/16/24 px; torrent rows remain 64 px. Use 16 px action/state icons, 600 for emphasis, readable 12–14 px content and secondary labels. Preserve the native layout adaptations needed for actual data, ETA/ratio, sorting, search, selection, grouped files and resizable panes.

Apply the approved quieter selection, stronger secondary contrast and neutral aggregate upload/download arrows. Settings retain all existing preferences, languages, autosave, busy/error rollback and focus restoration. Add retains the owned native window, both source flows, the collapsed-file choice, final path, selected size, errors, cancellation and confirmation rules; strengthen their hierarchy without importing browser-only controls or sample data. Primary/secondary button callbacks, accessibility and keyboard routes remain intact.

Engine, storage, manifests, persistence, platform integration, dependency versions and icon geometry are out of scope. Never remove an existing feature because an earlier web study did not depict it. Add no animation or recurring redraw work. Retain MIT, dependency notices and Slint attribution. Keep all supported locale catalogs consistent with any sentence-case/new label pairs.

Verify with the existing rendered menu/controller/add-window/settings tests, full locked checks at jobs 2, release and Mac lifecycle, then inspect the real native harness using an isolated loopback fixture. Record actual platform limits; local Mac evidence does not establish Windows/Intel physical acceptance.
