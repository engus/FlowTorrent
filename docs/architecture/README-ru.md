# Структура репозитория

Корень — Cargo workspace. Пакет Slint для Windows/macOS, UI, интеграционные фикстуры и упаковка находятся в apps/desktop. Движок и логика остаются в этом пакете до появления реального потребителя общей библиотеки.

- apps/website и apps/mobile резервируют исходники будущих приложений без выбора технологий и заявлений о готовых сборках.
- assets содержит общие ресурсы сборки; шрифты и их OFL-лицензия — в assets/fonts. Лицензии сохраняются при распространении.
- scripts и vendor остаются общими в корне. Корневые команды Cargo и Cargo.lock сохраняются.
- docs/brand содержит исходные брендбуки, docs/audits — аудит, docs/validation — датированные результаты, docs/superpowers — спецификации и планы. Исторические отчёты сохраняют исходные ревизии и ограничения проверок.
- _work игнорируется Git и содержит ценные рабочие материалы и выгрузки. Реальную работу нельзя удалять без разрешения автора. Исходные output и tmp целиком перенесены в _work/brand/output и _work/brand/tmp с проверкой хешей в _work/validation.
- _work/migration-backup сохраняет локальные файлы, патчи и исходный индекс старой основной папки. Нельзя восстанавливать старый индекс поверх новой структуры.
- target остаётся игнорируемым результатом Cargo. Версии зависимостей и идентификаторы приложения/сессии при переносе не менялись.

Отдельная рабочая копия AppKit-прототипа не менялась и не стала основным UI. Для текущего незакоммиченного переноса пока не заявляются коммиты и удалённый CI.
