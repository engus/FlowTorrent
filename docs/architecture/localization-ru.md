# Локализация

Согласованный для настольного приложения набор включает 14 языков. Он выбран для проекта и не является объективным мировым рейтингом языков. Английский и русский остаются контекстной исходной парой; переводы ещё на 12 языков хранятся в каталогах.

## Выбор и резервный язык

Настройки предлагают **системный язык** и 14 самоназваний. Сохранённый явный выбор имеет приоритет над системой. В системных тегах нормализуются подчёркивания и регистр, затем определяется язык. Неподдерживаемые локали дают английский. Поддерживается упрощённый китайский; традиционные теги с `Hant`, `TW`, `HK` или `MO` дают английский, чтобы не выдавать упрощённый перевод за традиционный. Другие неподдерживаемые варианты не создают отдельных каталогов.

Пути, имена торрентов и файлов, magnet-ссылки, имя автора и названия продуктов не переводятся. Форматирование следует существующим правилам единиц и десятичных разделителей приложения. Системные диалоги, пункты меню ОС и сведения сторонних компонентов могут использовать собственную локализацию.

## Работа с каталогами

- [messages.json](../../assets/locales/messages.json) связывает стабильные ID с контекстными парами `ru` / `en`. Контекстом служит полная пара: одинаковые английские слова в разных местах могут требовать разных переводов.
- 12 соседних языковых JSON содержат те же ID с непустыми переводами.
- [generate_translations.py](../../scripts/generate_translations.py) проверяет совпадение ключей, подстановок, числовых значений и покрытие исходников, затем создаёт [статические таблицы Rust](../../apps/desktop/src/ui/translations_generated.rs).
- Rust сохраняет вызовы `Locale::text(ru, en)`. Чистый [глобальный объект Slint Translations](../../apps/desktop/ui/translations.slint) передаёт поиск строки выбранной локали. Новый язык применяется после успешного сохранения настройки.

Из корня репозитория:

```sh
python3 scripts/generate_translations.py
python3 scripts/generate_translations.py --check
python3 -m unittest discover -s scripts/tests -p 'test_translations.py' -v
```

Для новой строки добавьте точную контекстную пару в `messages.json`, переведите её ID во всех дополнительных языковых каталогах, создайте таблицу и запустите проверку. При изменении формулировки меняйте исходную пару и все связанные переводы вместе. Не редактируйте созданную таблицу Rust вручную. Каталоги нужны при разработке: готовое приложение не загружает переводы, не обращается в интернет для локализации и не разбирает JSON во время работы. При отсутствии строки используется английский; проверка генератора должна выявлять пробелы до выпуска.

## Границы приёмки

Покрытие каталогов и автоматические проверки подтверждают структуру. Они не доказывают языковую точность или правильную компоновку на каждой нативной платформе. Новым переводам ещё нужна приёмка носителями; полная формальная матрица нативного UI для 14 языков не завершена. Проверяйте длинные подписи, переносы и сокращения, китайские / японские / корейские / казахские / украинские символы, обе темы, изменение размеров, клавиатуру и фокус, ошибки, последствия подтверждений, числа и единицы. Записывайте фактическую платформу, ревизию сборки и результат; генерация каталога сама по себе этих проверок не заменяет.
