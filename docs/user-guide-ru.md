# Руководство пользователя

Руководство описывает текущий интерфейс разрабатываемой версии 0.1.0. Тестовые сборки Windows не подписаны, Mac подписаны ad-hoc. Целевые системы исходного кода — Windows 10 22H2 / 11 x64 и macOS 14+ на Apple Silicon / Intel; незавершённая приёмка платформ отмечена в [контрольном списке релиза](release-checklist.md).

## Установка или запуск тестовой сборки

В Windows используйте предоставленный установщик для текущего пользователя. На Mac выберите сборку для своего процессора, откройте DMG и перетащите FlowTorrent.app в Applications. DMG содержит приложение; само открытие DMG не устанавливает его. Сборка из исходников описана в [README проекта](../README-ru.md) и [руководстве по тестовой упаковке](test-packages.md). Публичная загрузка 1.0 здесь не объявляется.

## Добавление и загрузка

1. Нажмите **«Добавить торрент»** для локального `.torrent` или соседнюю кнопку magnet, чтобы вставить ссылку. Нужен хеш BitTorrent v1; гибридные ссылки с v1-хешем поддерживаются. Чистый v2 не поддерживается. Вставляйте magnet в приложение: системная регистрация magnet-ссылок не включена.
2. Для magnet дождитесь метаданных. Поиск можно отменить до подтверждения загрузки.
3. Просмотрите состав, выберите нужные файлы и папку. Подтвердите начало. Совпадающие имена не перезаписываются молча: при конфликте нужна другая папка. Папка по умолчанию относится только к новым добавлениям.

**«Остановить»** ставит на паузу, **«Запустить»** продолжает. Завершённый активный торрент раздаётся до остановки, удаления или выхода. При восстановлении сначала проверяются сохранённые данные, затем продолжаются ранее активные передачи; остановленные вручную остаются остановленными. Приложение сохраняет собственные метаданные: исходный `.torrent` после добавления не нужен.

## Поиск торрентов и просмотр файлов

В боковой панели есть **«Все»**, **«Загрузки»** и **«Завершённые»**. «Загрузки» объединяет незавершённые записи, включая остановленные и ожидающие; это не счётчик текущего скачивания в трее. Поиск работает локально по названиям. Сортировка меняет порядок. **«Запустить все» / «Остановить все» действуют на весь реестр**, включая скрытые фильтром строки.

Выберите строку и нажмите её многоточие, чтобы открыть или переключить нижнюю панель сведений. Обычный выбор не открывает закрытую панель. Поиск и выбор с клавишей-модификатором показывают элементы множественного выбора. Действия панели относятся к указанному выбору. Для реального прогресса файлов, выбранных / исключённых файлов и поиска выберите один торрент; при множественном выборе объединённый список файлов не выдумывается.

Перетащите разделитель боковой панели для изменения ширины или сверните её до значков. Высота нижней панели меняется её разделителем. Размеры сохраняются после окончания жеста. Список файлов и колонка сведений прокручиваются независимо, действия остаются доступны.

Прогресс и скорости поступают от движка. Неизвестное оставшееся время обозначается явно. **Процент отдачи относится к сессии движка** и может сброситься после перезапуска; это не накопленный коэффициент за всё время. Автоматической остановки по коэффициенту нет.

## Настройки

Изменения сохраняются автоматически, панель остаётся открытой. На время сохранения конфликтующие элементы отключаются. При ошибке возвращаются сохранённые настройки и показывается сообщение.

- **Тема:** системная, светлая или тёмная.
- **Язык:** системный или один из 14 языков с самоназваниями. Неподдерживаемый системный язык даёт английский. См. [локализацию](localization-ru.md).
- **Автозапуск:** меняет только отдельную системную запись FlowTorrent после явного переключения. Открытие настроек его не включает.
- **Уведомления о завершении:** по выбору пользователя, не более одного на завершение. Запрет ОС или ошибка доставки не останавливают передачи.
- **Папка новых загрузок:** выберите папку; существующие файлы остаются на месте.
- **Общие лимиты скачивания и отдачи:** по умолчанию без ограничений; предустановки начинаются с 0,5 Мбит/с. Лимиты общие для торрентов, включая отдачу во время скачивания и раздачи. Мбит/с — десятичные биты: 0,5 Мбит/с = 62 500 байт/с. Прежнее нестандартное значение показывается отдельным неизменяемым текущим вариантом и сохраняется точно при изменении других настроек. Поля ручного ввода скорости в текущем UI нет.

## Работа в фоне и выход

Закрытие окна сохраняет передачи в фоне. В Windows откройте окно из трея, на Mac — из Dock или строки меню. **«Выйти»**, а на Mac также **Cmd+Q**, сохраняет состояние и завершает процесс.

Фирменный значок трея / строки меню сохраняется. Меню и подсказка показывают **↓ скачивание**, **↑ отдачу** и число записей именно в состоянии **скачивания** по существующим снимкам движка, в том числе при скрытом окне. Ожидание, проверка, пауза и раздача не входят в этот счётчик. Скорости суммарные и не являются тестом сети.

## Безопасное удаление и восстановление

**«Удалить из списка»** убирает сохранённую запись и оставляет скачанные файлы. **«Удалить торрент и файлы»** — отдельное подтверждаемое действие переноса выбранных файлов, принадлежащих записи приложения, в системную Корзину. Постоянное удаление не предлагается, чужие файлы не удаляются. Подтверждение указывает цели; по умолчанию выбрана отмена.

Если перенос в Корзину не завершился, сохраните промежуточные данные и журнал восстановления. Используйте предложенное открытие папки восстановления или повтор; не удаляйте эти данные вручную. При ошибке диска, прав или недоступного накопителя устраните причину и повторите. Приложение не переносит старые загрузки в другую папку молча. Повреждённое или более новое сохранённое состояние остаётся для восстановления, а не заменяется пустой сессией.

## О программе и поддержка

Откройте **«Справка → О программе FlowTorrent»** или кнопку в Настройках: там указаны настоящая версия пакета, автор, проект и компоненты с официальной атрибуцией Slint. Оттуда доступен [сайт автора](https://golota.me). **«Поддержать автора»** отключено до предоставления ссылки Ko-fi. Все функции бесплатны.
