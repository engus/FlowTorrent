# About window and release follow-up — 26 October 2026

The maintainer requested an About window with project description and https://buymeacoffee.com/engus. Implement it as a lightweight native Slint dialog over the existing window, reachable from Settings and a top-level Help menu. Use the existing theme, RU/EN, actual Cargo package version, brand symbol, author, project link and key component credits. Include the official AboutSlint widget and retain the footer attribution. Donation is optional and opens the supplied HTTPS URL in the system browser; no payment handling or remote content is embedded. Project/support destinations are fixed constants. Browser failures stay in the dialog and never affect transfers or saved settings. Escape/Close restores the originating screen and focus. Help→About is disabled while an Add Torrent or Add Magnet dialog is open. An incoming foreground preview, magnet resolution or duplicate-focus event dismisses About before presenting its requested pane; hidden Add controls must never receive confirmation through About.

Keep the existing isolated checkout and Mac/Windows shared UI. No AppKit prototype changes, dependency upgrades, public release, tags or installer uploads. ## Donation licensing

The pinned librqbit 9.0.1 package declares Apache-2.0, and the project license at that tag agrees: https://raw.githubusercontent.com/ikatson/rqbit/v9.0.1/LICENSE. Apache-2.0 grants royalty-free distribution rights; voluntary support does not require changing the engine. Preserve applicable licenses/notices and modification notices. Slint 1.18.1 is used under Royalty-free 2.0, as recorded in about.toml: https://slint.dev/agreements/slint-royalty-free-license.pdf. It permits desktop applications without royalties and requires attribution. The official AboutSlint widget belongs in an About screen accessible from the top-level menu; an official badge on the public download webpage is the alternative. This conclusion concerns dependency licensing, not payout eligibility or tax treatment.
