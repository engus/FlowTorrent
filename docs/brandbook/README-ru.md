## Ресурсы и лицензии

Подмножество графики и шрифтов приложения находится в [assets/brand](../../assets/brand): SVG логотипов / символов, значок приложения macOS и начертания Nunito с [текстом SIL OFL](../../assets/brand/OFL.txt). Для изменений клиента используйте эти ресурсы репозитория. Эта папка сохраняет PDF без дублирования всего большого дизайн-кита, его рендеров и инструментов сборки. Брендбуки описывают исходный состав кита; не каждый показанный экспорт скопирован в дерево исходников.

Утверждённый знак — замкнутая лента: сохраняйте порядок пересечений и готовую геометрию. Логотипы являются графикой, их не следует набирать заново. Для UI используется Nunito. Значки управления и состояний — отдельные [закреплённые ресурсы Lucide](../../assets/icons/lucide/README-ru.md) с полной [лицензией ISC / Feather MIT](../../assets/icons/lucide/LICENSE). Lucide не заменяет фирменные значки приложения / трея FlowTorrent.

Брендбуки задают дизайн, но не доказывают приёмку Finder, Dock, трея, Retina или Windows DPI. Наблюдения платформ относятся к [контрольному списку релиза](../release-checklist.md) и датированным отчётам. [MIT проекта](../../LICENSE), сторонние лицензии и официальная атрибуция Slint сохраняются.
