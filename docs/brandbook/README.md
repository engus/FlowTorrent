## Assets and licenses

The repository's app artwork and font subset are in [assets/brand](../../assets/brand): SVG wordmarks/symbols, the macOS app icon and Nunito font weights with [SIL OFL text](../../assets/brand/OFL.txt). Use these checked-in application assets when changing the client. This directory preserves the PDFs without duplicating the full large design kit, its renders or build tools. The brandbooks describe the design kit's original contents; not every export shown there is copied into the source tree.

The approved mark is a looped ribbon; retain its crossing order and use the supplied geometry. Wordmarks are artwork, not labels to retype. UI typography uses Nunito. Small control/status icons are separate [pinned Lucide assets](../../assets/icons/lucide/README.md), with their complete [ISC / Feather MIT license](../../assets/icons/lucide/LICENSE). Lucide does not replace the FlowTorrent app/tray identity.

The brandbooks are design guidance, not proof of Finder, Dock, tray, Retina or Windows DPI acceptance. Platform observations belong in the [release checklist](../release-checklist.md) and dated validation reports. The project's [MIT license](../../LICENSE), dependency notices and official Slint attribution remain in force.
