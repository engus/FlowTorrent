# Передача разработки Slint

Продолжать в codex/slint-release-readiness. Общий нативный Slint подключён к движку. AppKit изолирован. Текущая сборка target/local-macos/slint-parity-20261026/FlowTorrent.app собрана из 53a41e8; установленное приложение не заменялось. Ветка отправлена для CI; релиз, тег и загрузка установщиков не создавались. Актуальные доказательства — в [отчёте о соответствии макету и полном CI](slint-parity-validation-ru.md).

Прочитать [проверки и границы](slint-redesign-validation-ru.md), [решения переноса](superpowers/specs/2026-10-26-slint-redesign-ru.md) и [план](superpowers/plans/2026-10-26-slint-redesign-ru.md). Защита путей и сохранение состояния 1.0 остаются. Явное решение о Корзине меняет прежнюю область запрета удаления через UI; SecureStorage по-прежнему не удаляет файлы.

Оставшиеся физические проверки включают DPI/клавиатуру/Корзину/автозапуск Windows и Intel Mac. Результаты полного CI записаны в продолжении выше. Автозапуск меняет только собственную запись пользователя после Сохранить; тесты используют подставной provider. Системная тема получает события Winit на обеих платформах. Процент отдачи относится к сеансу. Перенос существующих загрузок и накопительная статистика не реализованы.

Не повторять аудит браузерного макета и не переписывать AppKit. Сохранить обычный остановленный торрент пользователя на NAS. Для настоящего движка/UI использовать examples/ui_smoke с новой абсолютной папкой собственных фикстур. Cargo --locked, -j 2, macOS 14.0. Публикация требует отдельного разрешения.
