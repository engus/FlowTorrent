# Передача разработки Slint

Продолжать в codex/slint-release-readiness. Общий нативный Slint подключён к движку. AppKit изолирован. Локальная сборка target/local-macos/slint-redesign-20261026/FlowTorrent.app; установленное приложение не заменялось. Публикации и push не было.

Прочитать [проверки и границы](slint-redesign-validation-ru.md), [решения переноса](superpowers/specs/2026-10-26-slint-redesign-ru.md) и [план](superpowers/plans/2026-10-26-slint-redesign-ru.md). Защита путей и сохранение состояния 1.0 остаются. Явное решение о Корзине меняет прежнюю область запрета удаления через UI; SecureStorage по-прежнему не удаляет файлы.

Следующие релизные этапы — полный CI, физические DPI/клавиатура/Корзина/автозапуск Windows и Intel Mac. Автозапуск меняет только собственную запись пользователя после Сохранить; тесты используют подставной provider. Системная тема получает события Winit на обеих платформах. Процент отдачи относится к сеансу. Перенос существующих загрузок и накопительная статистика не реализованы.

Не повторять аудит браузерного макета и не переписывать AppKit. Сохранить обычный остановленный торрент пользователя на NAS. Для настоящего движка/UI использовать examples/ui_smoke с новой абсолютной папкой собственных фикстур. Cargo --locked, -j 2, macOS 14.0. Публикация требует отдельного разрешения.
