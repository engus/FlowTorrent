# Передача разработки Slint

Продолжать в codex/slint-release-readiness. Последние изменения — белая светлая тема, изменяемая левая панель, нижняя панель сведений, Lucide и автоприменение настроек — перенесены в общий Slint и подключены к движку. AppKit изолирован. Текущая локальная сборка: target/local-macos/slint-drawer-20261026-b00b27d/FlowTorrent.app, исходники b00b27d; установленное приложение не заменялось. Актуальные результаты CI и ограничения: [проверка нижней панели](slint-drawer-validation-ru.md). Релиз, тег и загрузка установщиков не создавались.

Прочитать [спецификацию панели](superpowers/specs/2026-10-26-slint-drawer-ru.md), [план панели](superpowers/plans/2026-10-26-slint-drawer-ru.md), [проверки и границы](slint-redesign-validation-ru.md), [решения переноса](superpowers/specs/2026-10-26-slint-redesign-ru.md) и [план](superpowers/plans/2026-10-26-slint-redesign-ru.md). Защита путей и сохранение состояния 1.0 остаются. Явное решение о Корзине меняет прежнюю область запрета удаления через UI; SecureStorage по-прежнему не удаляет файлы.

Оставшиеся физические проверки включают DPI/клавиатуру/Корзину/автозапуск Windows и Intel Mac. Результаты полного CI записаны в продолжении выше. Автозапуск меняет только собственную запись пользователя при явном изменении этой настройки и успешном надёжном сохранении; тесты используют подставной provider. Системная тема получает события Winit на обеих платформах. Процент отдачи относится к сеансу. Перенос существующих загрузок и накопительная статистика не реализованы.

Не повторять аудит браузерного макета и не переписывать AppKit. Сохранить обычный остановленный торрент пользователя на NAS. Для настоящего движка/UI использовать examples/ui_smoke с новой абсолютной папкой собственных фикстур. Cargo --locked, -j 2, macOS 14.0. Публикация требует отдельного разрешения.
