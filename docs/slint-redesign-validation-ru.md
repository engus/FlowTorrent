# Кандидат Slint — 26 октября 2026

Проверенный макет подключён к AppController/librqbit в общем Slint. Это локальная тестовая сборка, не релиз 1.0. Прототип AppKit и установленное приложение не менялись.

Реализованы брендовые SVG/иконки и Nunito, Все / Незавершённые / Скачаны, поиск/сортировка, выбор по ID, общие Начать все / Остановить все, меню строк, настоящие скорости/ETA/процент отдачи за сеанс, проверенные байты файлов, папки/поиск и закреплённые действия. Обычный выбор не показывает чекбоксы. Полные детали запрашиваются только для открытого видимого торрента; объединение обновлений скрытого окна сохранено.

Настройки: системная/светлая/тёмная тема, RU/EN, явный автозапуск при входе, папка новых загрузок, уведомления, общие пресеты/свои лимиты. По умолчанию Без ограничений. Минимум нового лимита 0,5 Мбит/с = 62 500 Б/с, в UI точно 62,5 КБ/с. Старые значения сохраняются. Отмена возвращает сохранённые тему/язык. Winit обновляет системную тему на обеих платформах, сохраняя явную светлую/тёмную.

Удаление записи оставляет файлы. Удаление с файлами использует системную Корзину по явному решению пользователя. Подтверждение фиксирует ID/названия, начальный фокус Отмена. SecureStorage по-прежнему не удаляет данные. Отдельная операция сохраняет остановку, освобождает движок, проверяет закреплённые обычные файлы, отклоняет подмены/ссылки, переносит выбранные собственные файлы в закрытую папку того же диска и сохраняет журнал. Квитанция остаётся до надёжного удаления записи. Ошибки/прерывания сохраняют данные и запрещают создание пустых файлов заново. Посторонние файлы и пустые исходные папки остаются.

## Проверки

- Rust 1.92.0, --locked, -j 2, MACOSX_DEPLOYMENT_TARGET=14.0.
- fmt, Clippy всех целей с запретом предупреждений, все тесты: 130 тестов, 33 завершённых тестовых цели, без отказов.
- Release ARM и Mac lifecycle probe прошли. Использовано прежнее Mac-исключение build-override.strip=none для proc-macro; оптимизация исполняемого файла и Windows-профиль сохранены.
- Cross-target cargo check Intel Mac прошёл; физический запуск Intel не проверялся.
- Windows-зависимости и настоящие модули автозапуска/Корзины/staging проверены с Windows Rust std и Win32. Probe подставляет сторонние для них domain/persistence helpers: это не полная Windows-сборка и не CI.
- 40 Python-тестов упаковки прошли. Проверены plist, Mach-O, минимальная ОС, системные библиотеки, ad-hoc подпись и лицензии под неизменённый Cargo.lock. OFL приложена отдельно.
- Регрессии покрывают выбор/фильтры, детали и скрытое окно, повторные общие действия, Корзину остановленного торрента, подмены/ссылки, посторонние staging-записи, отказы/прерывания, устаревшее добавление с квитанцией, старые настройки, единицы скорости, отмену и откат фактической записи автозапуска при ошибке сохранения. Замечания свежего обзора воспроизведены и исправлены.

## Проверка на этом Mac и границы

Настоящий UI использовал отдельный реестр и локальный seeder. Фикстура 524 288 байт скачалась, показала проверенное завершение и остановилась через меню строки. Корзина сообщила успех: исходный файл и строка исчезли, активный журнал удалён. Приватность macOS запретила терминалу просмотр ~/.Trash; восстановление из Корзины не проверялось. Корзина не очищалась.

Фикстура с 40 файлами проверила системный picker, настоящий предпросмотр/подтверждение, ожидание/остановку, папки, поиск свёрнутых групп, восстановление сворачивания, закреплённые действия, поиск торрентов, пустой поиск и обычный выбор без чекбоксов. Проверены темы, RU/EN, отсутствие лимитов по умолчанию, минимальный пресет и Отмена. Отсутствие фокуса модального окна воспроизведено и исправлено; затем фокус Отмена и Escape прошли. Снимок: target/slint-redesign-validation-20261026/native-light-files.png, перед переименованием Пауза в Остановлен.

Пользовательские реестр/данные не использовались для скачивания/Корзины; остановленный торрент на NAS не запускался и не удалялся. Автозапуск не включался. До релиза нужны полный CI, физические DPI/клавиатура/Корзина/автозапуск Windows, Intel Mac и настоящий выход/вход. Возврат фокуса перенесён после успешного закрытия настроек. Проверка фокуса инструментом стала недоступна после скрытия тестового окна; полный физический проход сочетаний/фокуса остаётся ручной проверкой. Свежих измерений CPU/RAM нет. Процент отдачи явно относится к сеансу: накопительная статистика не сохраняется. Перемещение загрузок не добавлено, Повторить проверяет прежний путь.
