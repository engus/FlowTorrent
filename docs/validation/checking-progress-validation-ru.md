# Прогресс проверки — 27.10.2026

На скриншоте после перезапуска торрент размером 57 ГБ показывал Checking и пустую полосу с 0%. Закреплённый librqbit 9.0.1 уже сообщает ход инициализации через `TorrentStats.progress_bytes`, а общий объём проверки — через `total_bytes`. Адаптер намеренно оставляет подтверждённый скачанный объём нулевым до окончания инициализации; эта защита сохранена.

Временный `TorrentSnapshot.checking` передаёт отдельные счётчики обработанного/общего объёма только при инициализации. Поддерживаются восстановление с первоначальной паузой и активная инициализация. Интерфейс показывает переведённый статус с целым процентом, например Checking 37% / Проверка 37%, а янтарная полоса отражает ход проверки. Число у полосы сохраняет прежнюю точность до одного десятичного знака. После проверки прогресс и статус снова относятся к скачиванию. Знаменатель охватывает весь проверяемый движком объём, даже если выбранный размер скачивания меньше. При неизвестном/нулевом общем объёме процент не выдумывается; значения ограничены диапазоном и вычисляются без переполнения целых чисел.

Дополнительного хеширования, чтения файлов, опроса, сохранения состояния и новых зависимостей нет. Счётчики передаются с существующей публикацией снимков раз в 500 мс. Прогресс проверки не засчитывается в подтверждённый скачанный объём, не означает завершения скачивания и не вызывает уведомление о завершении. Защита файлов, владение манифестом и восстановление с первоначальной паузой сохранены. Файлы прототипа AppKit не менялись.
