# Двойной клик по торренту в Slint — 27.10.2026

Двойной клик по строке торрента вызывает тот же обработчик `details-requested(id)`, что и кнопка с тремя точками. Строка и её отдельно обрабатывающая нажатия область прогресса используют встроенное распознавание двойного клика Slint. Одиночный выбор, клики по прогрессу/ETA и правое контекстное меню сохранены. Новый двойной клик учитывает блокировку занятости, используемую кнопкой с тремя точками. Движок, зависимости, платформенный код и прототип AppKit не менялись.

Регрессионный тест отправляет настоящие события нажатия/отпускания мыши в отрисованное окно Slint. Проверяются одиночный выбор без запроса панели, запрос сведений нужного торрента двойным кликом по названию и прогрессу, блокировка при занятости и вызов контекстного меню правой кнопкой без запроса панели. До добавления обработчиков интерфейса тест падал с `double click did not request row details`; после изменения прошёл.

Проверено на этом Mac с закреплённым Rust 1.92.0, locked-зависимостями, двумя Cargo jobs и deployment target 14.0:

- Форматирование и строгий Clippy прошли.
- Все 161 Rust-тест в 35 тестовых исполняемых файлах прошли.
- Все 48 тестов упаковки/скриптов прошли; проверены 179 контекстных сообщений на 14 языках.
- Проверка жизненного цикла macOS прошла.
- Собрана оптимизированная тестовая ARM Mac-сборка `_work/exports/macos-double-click-20261027/FlowTorrent.app`; прошли проверка пакета, точных лицензий зависимостей и строгая проверка ad-hoc-подписи. Developer ID и notarization отсутствуют; автоматически она не запускалась.

Локальные журналы и хеши исходников находятся в `_work/validation/double-click-20261027/`. Получив последующую сборку с прогрессом проверки, которая также включает двойной клик, владелец подтвердил работу всех проверок на этом Mac. Отдельные физические сценарии кликов по пунктам не перечислялись. Приёмка Windows остаётся отдельной. Агент оставил уже запущенное приложение работающим; автоматические проверки не означают замену его исполняемого файла.
