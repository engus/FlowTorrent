# Время ожидания нативного lifecycle-примера Slint — 27 октября 2026

Задание Mac Intel в [прежнем PR-прогоне](https://github.com/engus/FlowTorrent/actions/runs/40497144406) прошло сборку, тесты и Clippy, но упало с `native modal lifecycle did not run`. Пример требовал завершить асинхронное создание нативного модального окна к фиксированному таймеру в 1,5 секунды от запуска цикла событий, поэтому проверка зависела от скорости старта runner и создания окон.

Теперь 1,5 секунды наблюдения за скрытым окном начинаются только после завершения присоединения/отсоединения модального окна. Независимый watchdog на 30 секунд по-прежнему завершает проверку с ошибкой при незавершённом создании модального окна или не завершившемся скрытом цикле. Сохранены проверки нативного модального присоединения, порядка delegate-вызовов, повторного открытия, времени жизни значка и запрета позднего восстановления значка при выходе. Меняется только диагностический пример Slint; отдельный прототип AppKit и нативные обработчики приложения не менялись.

Исправленный пример, строгий Clippy, 164 теста приложения, 18 тестов bencode и doc-тесты прошли локально на ARM Mac перед коммитом. Прежнее удалённое падение относится к старому примеру и не является успешным результатом для этой версии. Новый CI на трёх платформах разрешён с отключённой загрузкой установщиков; фактический результат хранится в GitHub Actions с проверенной ревизией. Публикация релиза не разрешена.
