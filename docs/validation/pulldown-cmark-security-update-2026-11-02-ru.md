# Обновление безопасности транзитивного парсера — 2 ноября 2026

Первый полный CI для `experiments/file-priorities`, исходники
`10d647b94eab90e2b998a5318fef444816ea6710`, не прошёл проверку зависимостей:
[Check 41416575744](https://github.com/engus/FlowTorrent/actions/runs/41416575744).
Она обнаружила [RUSTSEC-2026-0414](https://rustsec.org/advisories/RUSTSEC-2026-0414.html)
в существующей транзитивной зависимости Slint `pulldown-cmark 0.13.4`. Advisory
описывает экспоненциальный рост событий при разборе Markdown с включёнными wikilinks.
Это результат проверки зависимости, а не доказательство эксплуатации FlowTorrent.

Отдельное исправление меняет только версию и checksum этого пакета в `Cargo.lock`
на upstream `0.13.5`. Архив опубликованного crate сверен с checksum crates.io;
его нормализованный манифест отличается только версией. Cargo принимает граф
с `--locked`. Прямые закреплённые зависимости, Slint 1.18.1, librqbit 9.0.1,
toolchain и исходники приложения этим исправлением не изменены.
Исключения для advisory и ослабление проверок CI не добавлялись.

Локальный cargo-deny 0.20.2 теперь сообщает `advisories ok, licenses ok, sources ok`.
Существующее неблокирующее предупреждение об отозванной версии `clipboard-win 5.4.1`
остаётся; посторонние зависимости в рамках этого исправления не обновляются.

Локальная проверка Mac ARM после обновления: fmt, строгий all-target Clippy и все
199 Rust-тестов (44 harness, без ошибок и пропусков) прошли. Release-сборка и
трёхплатформенный CI оцениваются отдельно от этой локальной проверки.

Сырые metadata, подтверждение checksum и логи сохранены в игнорируемом каталоге
`_work/validation/file-priorities-ci-20261102/`. Полный платформенный CI следует
оценивать для исправленного коммита, а не прерванных первых запусков. Загрузка
установщиков отключена; main/AppKit, релизы, теги и публикации не затронуты.
