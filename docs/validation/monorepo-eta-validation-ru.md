# Перенос и оставшееся время — 27 октября 2026

Доказательства ниже получены на тогда ещё незакоммиченном дереве `codex/monorepo-eta-20261027` от `58195bb`. Позднее владелец разрешил коммиты, push и новый CI на трёх платформах с отключённой загрузкой установщиков. CI предыдущей ветки не доказывает этот перенос.

## Отображение времени

Согласована максимальная текущая ETA активных незавершённых торрентов; остановленные исключены, любая неизвестная активная оценка делает общий срок неизвестным. В трее значок Lucide и ЧЧ:ММ (часы:минуты, округление вверх), «меньше 1 мин» до минуты, прочерк при неизвестности. Mac показывает часы/время перед суммарными скоростями, Windows — часы в третьем пункте. Подсказка/описание изображения содержит локализованное название оставшегося времени. Таймер не добавлен; секунды внутри одной показанной минуты не будят скрытый UI при постоянных скоростях.
