# Защита обработчиков передачи — 2 ноября 2026

Статус: исправление и полный локальный прогон на Mac ARM подтверждены; отмеченный долг закрыт.

Закрывает долг защиты прямых вызовов из [ревью меню приоритетов](priority-menus-2026-11-02-ru.md), в `experiments/file-priorities`, база `142f2bb75a4c4c8769f15a44d0f4fface33406b0` плюс сохранённая несохранённая работа. Без коммитов/push/merge/публикации.

Выбор файлов, приоритет файла и приоритет торрента используют общую проверку допуска. Она отклоняет вызов, если UI ещё не готов, занят, завершает работу, ожидает команду либо показывает настройки, предпросмотр добавления, ввод/поиск magnet, подтверждение удаления или About. Команды файлов также проверяют поиск метаданных в достоверном снимке, пока флаги диалога ещё не обновились. Сохраняются проверки настоящих ID торрента/файла, проверки/ошибки и скрытого состояния. При отказе возвращается каноническое состояние элементов, в том числе при уже ожидающей такой же операции.

Общая очередь команд приложения не менялась: подтверждение/отмена диалогов и сохранение настроек сохраняют собственные правила. Движок, манифест/схема, Slint-макет, зависимости, платформенный код и AppKit-прототип в этом исправлении не менялись.

## Доказательства

Тесты вызывают настоящие обработчики, установленные `bind_callbacks` в headless-окне Slint, и читают настоящую ограниченную mpsc-очередь. Обработчики не подменяются, поведение движка не имитируется. После снятия каждой блокировки проверяется, что тот же обработчик снова отправляет ровно одну команду с настоящими ID торрента/FileId. При отказе сохраняются ожидающая операция, флаги жизненного цикла, существующая ошибка и окно About.

Четыре новых теста падали до исправления: команда проходила при занятости системного выбора файла без ожидающей операции, в About, до готовности UI и при поиске метаданных. После исправления все четыре проходят. Проверены три вида изменения; предпросмотр, ввод/поиск magnet, настройки, подтверждение удаления, рассогласованные busy/pending, скрытые снимки и возврат доступности после закрытия. Прежние тесты отрисованных элементов, возврата значений и устаревших ID остаются в полном наборе.

Итог: **199 passed, 0 failed, 0 ignored**, 44 набора. Четыре новых теста проверяют 36 заблокированных вызовов и 36 успешных вызовов после снятия блокировок.
