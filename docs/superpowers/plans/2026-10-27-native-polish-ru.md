# План доработок нативного UI

**Цель:** настоящий перезапуск и пять исправлений из запроса.
**Спецификация:** [запрос и выбор реализации](../specs/2026-10-27-native-polish-design-ru.md).
Выполнение здесь, TDD, один итоговый независимый read-only обзор. Rust 1.92, Slint 1.18.1, librqbit 9.0.1, Cargo --locked/-j2, deployment14. Основной dirty checkout и AppKit-прототип сохранить; без релиза/тегов/установщиков и обновления версий зависимостей.

## 1. Меню и логотип
- [ ] Настоящий перезапуск обычного приложения с OFF, вернуть ON и записать доказательства.
- [ ] RED точная однострочная EN/RU summary, суммы и число активных загрузок, пустой список/overflow/языки.
- [ ] TrayStatus.summary, один обновляемый пункт Mac, полная подсказка, template image, символ бренда 24px в заголовке.
- [ ] GREEN целевые тесты, lifecycle/нативная проверка и коммит.

## 2. Правый клик
- [ ] RED выбранная строка сохраняет группу, невыбранная заменяет выбор, стабильный ID после сортировки, команды и подтверждение для правильных целей.
- [ ] Подключить TorrentMenu к правой кнопке и клавиатуре; существующие group-команды, папка/копирование только для одного. Три точки и глобальные кнопки не менять.
- [ ] GREEN controller-тесты, нативный правый клик, коммит.

## 3. Модальное добавление
- [ ] RED координатор с подставной нативной lease: один child, magnet→preview, данные/отмена/крестик/busy, устаревший ID, очередь, отсутствие окна вне добавления, cleanup при ошибке/выходе.
- [ ] ui/add-window.slint и UI-thread AddWindowCoordinator: отложенная объединённая синхронизация, модели/ошибки/тема/язык, проверка показанного ID, weak child для родителя picker. Удалить встроенные панели добавления, сохранив список и API callback.
- [ ] src/platform/modal.rs: AppKit sheet/Win32 owner из настоящих handles, завершать lease до скрытия/уничтожения окна и восстанавливать родителя. Без вложенного блокирующего modal loop, таймера и второго состояния движка.
- [ ] GREEN controller/координатор/lifecycle и собственные локальные фикстуры: файл/magnet, длинный список, cancel/Escape/крестик, picker, дубликат/очередь, темы/языки, блокировка и восстановление родителя, сохранение трея при скрытии.
- [ ] Полные fmt/Clippy/Rust/Python/каталоги, свежий обзор с одним исправляющим проходом, CI трёх целей без упаковки; отдельная оптимизированная тестовая .app, парные доказательства и коммиты.

Файлы и точные интерфейсы перечислены в английском плане. Все действия используют текущие безопасные команды/подтверждения. Активную пользовательскую загрузку не менять, кроме запрошенного ограниченного перезапуска.
