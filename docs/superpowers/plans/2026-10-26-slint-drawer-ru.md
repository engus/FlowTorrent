# План переноса нижней панели Slint

**Цель:** перенести утверждённый макет с белым основным фоном в общее нативное приложение.
**Архитектура:** прежние controller/command/snapshot; совместимые настройки размеров; явный ограниченный просмотр файлов. Движок и Корзину не переписываем.
**Стек:** Rust 1.92, Slint 1.18.1, librqbit 9.0.1; статические SVG Lucide.
**Спецификация:** ../specs/2026-10-26-slint-drawer-ru.md
**Ограничения:** текущий worktree codex/slint-release-readiness; AppKit изолирован; Cargo --locked/-j 2, macOS 14.0. Без релиза/тегов/загрузки установщиков. RU/EN, лицензии и бейдж сохранены.
**Фокус обзора:** отказ/быстрые изменения настроек и откат ОС; точные старые лимиты; закрытие/фильтры/скрытый просмотр; минимальное окно с длинными путями/многими файлами; лицензия иконок в обоих пакетах.

1. [ ] RED: headless-тест автоматической отправки UpdateSettings, открытой панели после успеха, отката после отказа, отсутствия записи при открытии и сохранения 20 000 Б/с. Реализовать через прежнюю транзакцию, убрать ручной лимит и Сохранить/Отмена; GREEN и коммит.
2. [ ] RED: явный просмотр/закрытие с сохранением выбора, фильтры и миграция/границы UiLayout. Реализовать настройки размеров 180/false/320, callback многоточия, отключение ненужного InspectDetails. Перенести сворачиваемую панель и нижние две колонки с закреплёнными действиями/поиском. Проверить нативную отрисовку, 800×640 и клавиатуру; коммит.
3. [ ] RED: лицензия Lucide в пакете. Добавить закреплённые SVG/полную лицензию и единый Icons, заменить управление/состояния, сохранить брендинг приложения/трея, сделать основной текст кнопок белым. Проверить упаковку обеих платформ; GREEN и коммит.
4. [ ] fmt, строгий Clippy/тесты всех целей, Python, release ARM и lifecycle. Настоящие изолированные UI/движок, обе темы/RU/EN, компактное окно, автоматические настройки. Свежий независимый обзор, исправления важных замечаний через регрессии. Локальная тестовая .app без замены установленной. Отправка рабочей ветки и три цели основного CI с ожиданием результата; без загрузки установщиков. Парные отчёты с точными версиями/ограничениями.
