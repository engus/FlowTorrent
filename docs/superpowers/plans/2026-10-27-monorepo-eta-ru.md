# План структуры и ETA

Выполнение здесь через executing-plans и TDD, один независимый read-only обзор в конце. Коммиты без подтверждения запрещены.

Цель: согласованный перенос и общая ETA в трее. Корневой Cargo workspace, один desktop-пакет, общие ресурсы/scripts/vendor в корне. Rust 1.92, Slint 1.18.1, librqbit 9.0.1; --locked, -j2, deployment14.

[Согласованная спецификация](../specs/2026-10-27-monorepo-eta-ru.md). Сохранять реальные материалы, исходный индекс, версии/lockfile, безопасность хранения/сессий и изоляцию AppKit. Коммиты/push/релизы/загрузка установщиков запрещены до следующего решения. Физические проверки не подменяются CI.

Обзор: корень workspace против корня пакета, сканирование переводов после переноса, notices/упаковка/Windows-команды, парные документы и свежие результаты, ETA при паузе/неизвестности/переполнении и скрытые обновления.

- [x] RED тесты максимальной ETA, паузы, неизвестности, завершения, округления/переполнения и обновления при постоянной скорости; RED сканирования apps/desktop.

- [x] GREEN ETA на обеих платформах без таймеров/изменения движка. Metadata --locked, fmt, Clippy, Rust/Python/каталоги и lifecycle. Lockfile и версии без изменений.
