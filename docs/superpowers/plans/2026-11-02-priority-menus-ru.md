# План переноса меню приоритетов

> Выполнять последовательно через executing-plans и TDD, затем одна независимая проверка. Сохранить несохранённую работу; без коммитов, push и публикации.

**Цель:** согласованные значки и контекстное меню с настоящими независимыми приоритетами торрентов и файлов.
**Архитектура:** манифест v4 → надёжная транзакция политики с паузой → переносимая взвешенная очередь общего скачивания; прежние приоритеты файлов сохраняются.
**Технологии:** Rust 1.92.0, locked, librqbit 9.0.1, Slint 1.18.1, jobs 2, Mac deployment 14.0.
**Спецификация:** [дизайн эксперимента](../../architecture/priority-menus-experiment-ru.md).

## Общие ограничения

Main/AppKit/другие эксперименты и безопасность файлов неизменны. Парные RU/EN документы. Normal по умолчанию. Без новых настроек, зависимостей, релизов и загрузки установщиков. Сохранять исторические результаты и локальные резервные копии.

## Проверка рисков

Отмена и изменение лимита не блокируют очередь; число пиров не увеличивает долю; неактивные торренты не копят кредит. Изменения файлов не понижают схему 4. Ошибка/будущая схема не применяет несохранённую политику. Цель меню сохраняется при перестроении строк и работе клавиатуры. Занятость, модальные окна и выбор проверяются и в обработчиках Rust.

### Этап 1: Сохранение приоритета торрента

- [x] RED: схема v4, старые значения, защита повреждённых данных; изменение/перезапуск, ошибки записи и движка.
- [x] GREEN: поле приоритета, API движка, восстановление и общая надёжная транзакция с паузой.
- [x] Проверить тесты хранилища/контроллера.

### Этап 2: Веса запросов загрузки

- [x] RED: настоящие доли независимо от числа пиров, отмена/простой/смена лимита, отсутствие замедления без лимита; локальная передача двух торрентов и смена предпочтения.
- [x] GREEN: переносимая общая очередь, атомарный приоритет до передачи, адаптер.
- [x] Проверить очередь и реальные передачи.

### Этап 3: Slint

- [x] RED: правый клик и кнопки файла/торрента передают правильные ID, отмечают текущее значение, не меняют его при открытии, соблюдают занятость и узкое окно.
- [x] GREEN: общие значки/пункты, поле и обработчик торрента, стабильное меню файла вне виртуальных строк; прежние действия и чекбоксы.
- [x] Проверить UI и по возможности нативное окно.

### Этап 4: Финальная проверка

- [x] fmt, строгий Clippy, все тесты, locked release, Mac lifecycle; независимая проверка, воспроизводящие тесты и исправления.
- [x] Парные результаты/handoff и границы проверки платформ. Без коммитов/push/merge/публикации.
