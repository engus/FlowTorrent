# Этап 1: выбор файлов

Спецификация: [одобренное поведение эксперимента](../../architecture/file-selection-experiment-ru.md).
Рабочая копия `file-priorities/FlowTorrent`, ветка `experiments/file-priorities`, база `142f2bb`.

1. Сначала тесты версии манифеста 2, пустого выбора при восстановлении и защиты уведомлений; сохранить v1 и защиту будущих/повреждённых файлов.
2. Тесты смены выбора остановленного движка с проверкой ID; локальная загрузка нескольких файлов, повторное включение, общие куски.
3. Тесты последовательного переключения через контроллер: сохранение намерения, ошибки, остановка/запуск, восстановление, быстрые команды, принадлежность файлов для Корзины.
4. Чекбоксы Slint для одного торрента, настоящий FileId в callback, блокировка при проверке/ошибке, локализованный пустой выбор.
5. fmt, строгий Clippy, все тесты, release и lifecycle probe с -j2/locked. Независимый обзор ветки, исправление важных замечаний, фактические результаты и ограничения. Без коммитов/push/merge/публикации.

Фокус обзора: ошибки сохранения/движка, прерванные операции, пустой выбор и восстановление, старые клиенты, устаревшие команды UI, завершённые торренты, общие пограничные куски, закреплённые Windows-дескрипторы, принадлежность файлов для Корзины, отсутствие ложного завершения/уведомления.

## Проверенный результат

Пункты 1–4 завершены. Пункт 5: 176/176 тестовых записей (0 пропусков), fmt и строгий Clippy, локальный release с описанным параметром сборки и lifecycle Mac пройдены. Замечания P2 независимого обзора и откат чекбокса при ошибке отправки воспроизведены RED и проверены GREEN. [Результаты](../../validation/file-selection-stage1-2026-10-31-ru.md).
