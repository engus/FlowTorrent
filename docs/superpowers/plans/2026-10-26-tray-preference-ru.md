# План переключателя значка и фонового режима

**Цель:** перенести утверждённый макет v45 в Slint и исправить самопроизвольное исчезновение значка при скрытии окна.

Совместимая настройка UI включена по умолчанию, сохраняется существующей надёжной транзакцией. Значок живёт независимо от основного окна. Только явное выключение или выход убирают значок. На Mac — строка меню и пояснение про Dock, на Windows — трей и способ повторного открытия. Четырнадцать языков, без новых runtime-зависимостей и фонового опроса. Причина регрессии устанавливается до выбора исправления.

Текущий изолированный checkout; основной грязный main и AppKit-прототип не трогать. Не публиковать релиз, теги и установщики. Cargo --locked, -j2, deployment14. Старые настройки получают true; false сохраняется; повреждённые оригиналы защищены. Изменение значка применяется только из сохранённого снимка, ошибка возвращает контроль и фокус. Один значок, актуальные язык/скорости и окончательное завершение при выходе.
