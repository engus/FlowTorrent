# Доработки нативного UI — запрос 27 октября

Пользователь подтвердил переключатель и сохранение значка при скрытии, запросил настоящий перезапуск и пять конкретных изменений. Это явно меняет прежнее оформление заголовка, страницы добавления и меню. Сохраняются движок, безопасное хранение, Корзина, совместимость Windows и изоляция прототипа AppKit. Релиз, теги и установщики не публикуются.

- В обычном приложении Mac проверить выключенную настройку через штатный выход/запуск, затем вернуть исходное включённое состояние. Не менять намерения загрузок, автозапуск, разрешения уведомлений, папку и лимиты.
- Логотип строки меню Mac сделать системным template image: монохромным, автоматически белым/тёмным под фон. Dock, иконку приложения и Windows tray оставить цветными.
- Вернуть правый клик по строке: Начать/Остановить/Повторить по состоянию, папка, копирование magnet, удаление записи и отправка файлов в Корзину. Использовать стабильные ID и существующие подтверждения. Клик по выбранной строке сохраняет групповое выделение; по невыбранной выбирает её. Три точки продолжают открывать сведения. Выбор сам не запускает передачу.
- Вместо TORRENTS в развёрнутой панели — цветной символ бренда 24 логических пикселя, по центру высоты кнопки сворачивания. Высота заголовка и свёрнутая полоса 56 пикселей сохраняются.
- В меню Mac — одна неактивная строка `↓ <скачивание> · ↑ <отдача> · Скачиваются: <число>`. Сохраняются реальные суммы, подсказка, языки и событийные обновления. Меню трея Windows может сохранить прежнее оформление.
- Ввод magnet и подтверждение папки/файлов перенести в отдельное модальное окно Slint поверх главного, со списком позади. Кнопка файла по-прежнему открывает системный picker; magnet после получения метаданных переходит к подтверждению в том же окне. Отмена/Escape/крестик отменяют текущее добавление, крестик блокируется во время фиксируемой команды. Используются прежние выбор файлов, no-clobber и асинхронные команды; picker папки принадлежит новому окну. Успех закрывает окно. Устаревшие callback предыдущего торрента не действуют на следующий. Окно не должно быть поверх чужих приложений.

Выбор реализации: существующие закреплённые Slint/Winit и платформенные crates; document sheet AppKit и отключённый владелец Win32 с гарантированным восстановлением. Без блокирующего вложенного modal loop и фонового опроса. Размер около 640×560 логических пикселей, изменение размера, прокрутка файлов и закреплённые действия. Тема/язык главного окна. Между разными preview ID окно пересоздаётся; magnet→preview остаётся в одном окне. Callback проверяет ID показанного preview.

Встроенная страница не соответствует запросу отдельного окна; overlay внутри приложения не даёт нативного владения. Новая UI-библиотека расширила бы объём и нарушила общий Slint. Нативное дочернее окно — выбор реализации этого конкретного запроса.
