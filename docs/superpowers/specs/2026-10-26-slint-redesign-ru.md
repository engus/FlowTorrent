# Перенос проверенного макета в Slint

26 октября пользователь разрешил перенос макета v42 в общий интерфейс Rust/Slint для Mac и Windows. Этот документ заменяет прежние ограничения spec-1.0.md только для перечисленных возможностей. AppKit изолирован; публикация релиза, тегов и установщиков не разрешена.

## Поведение
- Брендовые логотипы, Nunito, нейтральные поверхности, бирюзовые действия; состояния обозначаются цветом и текстом. Сохраняются Made with Slint и лицензии.
- Слева Все / Незавершённые / Скачаны, внизу Настройки. Поиск локальный по имени; стабильная сортировка.
- Начать все / Остановить все всегда действуют на весь реестр. Три точки строки и закреплённые действия справа — на указанный торрент. Обычный клик открывает сведения без чекбоксов; поиск и выбор с модификаторами показывают чекбоксы. Выбор хранится по ID и согласуется после фильтрации и удаления.
- Прогресс слева направо. Незавершённые показывают скорость скачивания, завершённые — отдачу и отданный процент. Прогресс раскрывает ETA; неизвестное время обозначается явно. Внизу зелёная стрелка скачивания и красная отдачи.
- Список файлов прокручивается отдельно от закреплённых кнопок. Показываются реальные проверенные байты, выбор/исключение и пути. Детали запрашиваются только для открытого торрента.
- Добавление использует существующие безопасные предпросмотры .torrent и magnet, проверку дублей и запрет перезаписи.
- Настройки: системная/светлая/тёмная тема, RU/EN, автозапуск, папка новых загрузок, уведомления и общие лимиты. По умолчанию Без ограничений; пресеты и своё значение в Мбит/с. Минимум нового лимита 0,5 Мбит/с = 62 500 Б/с. Старые допустимые значения сохраняются точно; новые поля получают безопасные значения по умолчанию. Сохранить/Отмена явные; папка не перемещает существующие данные.
- Сохраняется Повторить. Перемещение существующих загрузок не добавляется: при недоступной папке показывается ошибка, Повторить проверяет её снова.
- Удаление записи оставляет файлы. Пользователь отдельно выбрал Корзину для удаления с файлами. Подтверждение фиксирует ID и последствия; начальный фокус Отмена. Безвозвратного удаления нет.

## Архитектура и безопасность
AppController владеет реестром, ограниченные команды и watch-снимки сохраняются; Slint работает на главном потоке. Групповые команды сохраняют намерение до действия. Ошибочные торренты не запускаются вслепую. Скрытое окно сохраняет объединение обновлений, подробности файлов не обновляются для всех строк.

Счётчики берутся из librqbit. До введения сохраняемого накопительного счётчика отдача обозначается как значение текущего сеанса. Старый минимум движка сохраняется для совместимости, новый применяется к редактируемому значению UI.

Корзина — отдельная операция приложения, удаление SecureStorage остаётся запрещено. Сначала сохраняется остановка, затем освобождается движок. Обрабатываются только выбранные файлы из собственного манифеста. Родители открываются безопасно; ссылки, reparse и hard links запрещены. Файлы закрепляются дескрипторами и перемещаются в закрытую временную папку того же диска; идентичность проверяется перед системной Корзиной. Неожиданный объект туда не отправляется. Журнал восстановления и данные сохраняются при ошибке/прерывании, ошибка видна пользователю. Автоудаления восстановления нет. Запись удаляется только после успеха. Тесты используют подставной backend и собственные фикстуры.

Автозапуск меняет только собственную запись FlowTorrent, конфликтующие записи сохраняются. Открытие настроек и тесты не включают автозапуск. Изменения применяются при Сохранить и откатываются при ошибке сохранения.

## Проверка
Тесты выбора/поиска/сортировки, точных единиц скорости и старых настроек, групповых намерений/ошибок, реального прогресса файлов, отказов Корзины и отмены настроек. Rust 1.92, --locked, -j 2. Изолированное настоящее приложение Mac и lifecycle. Сохраняются CI-цели Windows x64, Mac ARM/Intel; CI и браузерный макет не заменяют физические проверки.
