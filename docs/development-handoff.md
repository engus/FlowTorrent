## Что сделано в этапе 9

- Сохранение исходной ошибки повреждённой сессии при отказе команды, защита от чрезмерной вложенности bencode, восстановление при открытом внешнем читателе Windows, немедленная пауза после повторной попытки без зависания в Checking.
- Настоящие локальные загрузки с разрывом/возвратом TCP-соединения, перепроверкой одного повреждённого куска, управляемыми StorageFull/PermissionDenied на реальной записи и независимой работой второго торрента. Системный диск не заполнялся, сеть ОС не менялась.
- Исправлен прогресс выбранного файла на границе куска: ровно 50 000 байт вместо 53 616 с соседними байтами; проверено после восстановления без источника.
- Проверен общий лимит отдачи на двух независимых загрузчиках. Исправлен счётчик тестовой фикстуры: учитываются проверенные байты файлов, а не сбрасываемый upstream-счётчик сканирования.
- На Mac воспроизведён реальный `EMFILE` для 256 файлов при soft FD limit 64. Unix-инициализация теперь один раз вызывает `librqbit::try_increase_nofile_limit()` в пределах inherited hard limit и лимита Darwin. Оба Mac проходят регрессию; глобальные настройки ОС не меняются. Ветка `codex/stage9-nofile-limit` сохраняет red→green историю.
- Добавлен release-only инструмент `measure_resources`, отдельный процесс seeder, CSV/метаданные и ручной workflow Release validation. Исправлены измерения скрытого окна после первой отрисовки и чтение масштаба после запуска event loop.
- Сохранены [реальные измерения](performance.md) на трёх CI-целях и локальной Windows, плюс 300 секунд hide/show. Локально пустое окно занимает около 34 МиБ working set, пять активных загрузок — 39 МиБ. Это управляемая нагрузка без публичного discovery и IPC, не универсальная граница памяти клиента.
- На Windows просмотрен список из 20 записей при Slint overrides 1/1,25/1,5/2; настройки при 1/1,5/2, развёрнутые лимиты при 2, Tab/Enter и видимый фокус. Изменения DPI самой ОС не делались.

## Зафиксированные решения и локальная среда

Rust 1.92, librqbit 9.0.1, Slint 1.18.1. Четыре настройки: папка, уведомления, общий лимит загрузки и отдачи. По умолчанию скорость не ограничена; минимальный включённый лимит — 0,02 МБ/с. После скачивания продолжается раздача; её останавливает «Пауза». MIT автора, лицензии зависимостей и Slint badge сохраняются. Исправление LSD на Mac не удалять.

```powershell
cargo fmt --all -- --check
cargo clippy --locked --all-targets -j 2 -- -D warnings
cargo test --locked --all-targets -j 2
cargo build --locked --release -j 2
```

Cargo на текущей машине: `C:\Users\Engus\.cargo\bin`. Последние локальные all-targets запуски остановлены Windows App Control с кодом 4551 до выполнения тестов; повтор без изменений тоже блокировался. Защита/ACL не менялись, обход блокировки не применялся. Полный итоговый набор подтверждён CI; локальные fmt/check/Clippy и release-сборки прошли.

Иногда upstream Slint build script получает PermissionDenied при перезаписи `target/{debug,release}/build/SLINT_DEFAULT_STYLE.txt`. После полного завершения Cargo можно удалить только проверенный шестибайтный сгенерированный файл со значением `fluent` и повторить ту же команду. Не менять ACL или защиту системы. Ограничивать локальный параллелизм двумя jobs; прежняя перегрузка линковки и восстановление Git описаны в истории, текущий Git исправен.
