# About репозитория GitHub

Подготовленные метаданные для `engus/FlowTorrent`. Это проверяемый черновик; наличие файла не означает изменения настроек удалённого репозитория.

**Описание** — для GitHub используется английский текст:

> A free, ad-free BitTorrent desktop client for Windows and macOS, built with Rust and Slint.

**Темы**

```text
bittorrent torrent-client desktop-app rust slint windows macos librqbit open-source ad-free
```

**Website / домашняя страница проекта:** оставить пустой до появления настоящего сайта проекта и согласования URL. [Репозиторий GitHub](https://github.com/engus/FlowTorrent) остаётся основной ссылкой проекта. [golota.me](https://golota.me) — личный сайт автора, ему место в ссылках автора, а не в поле сайта проекта.

**Автор:** Yevgeniy Golota · engus — [golota.me](https://golota.me).
