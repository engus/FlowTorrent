# О программе и дальнейшие шаги к релизу — 26 октября 2026 года

Автор запросил окно «О программе» с описанием проекта и https://buymeacoffee.com/engus. Реализация — лёгкий диалог Slint поверх текущего окна, доступный из настроек и верхнего меню «Справка». Прежние темы, RU/EN, настоящая версия Cargo, фирменный символ, автор, ссылка на проект и сведения о лицензиях. Официальный AboutSlint и прежняя атрибуция внизу сохраняются. Поддержка добровольная; HTTPS-ссылка открывается в системном браузере, без встроенных платежей и удалённого содержимого. Адреса проекта/поддержки фиксированы. Ошибка браузера показывается в диалоге и не меняет загрузки/настройки. Escape/Закрыть возвращает исходный экран и фокус.

Прежний отдельный checkout и общий UI Mac/Windows. Без изменений прототипа AppKit, обновления зависимостей, публичного релиза, тегов и загрузки установщиков. Проверки: допустимые/неизвестные ссылки, ошибка браузера и локализация, headless-открытие/закрытие без engine/settings-команд; нативные темы/RU/EN/клавиатура/фокус; обязательные локальные проверки --locked и основной CI трёх платформ. Коммит реализации и проверенная передача состояния.

## Лицензии и донаты

Закреплённый пакет librqbit9.0.1 указывает Apache-2.0, текст проекта в этом теге совпадает: https://raw.githubusercontent.com/ikatson/rqbit/v9.0.1/LICENSE. Apache-2.0 разрешает распространение без роялти; добровольная поддержка не требует смены движка. Лицензии, применимые уведомления и отметки изменений сохраняются. Slint1.18.1 используется по Royalty-free2.0, как записано в about.toml: https://slint.dev/agreements/slint-royalty-free-license.pdf. Настольные приложения разрешены без роялти с атрибуцией. Официальный AboutSlint должен находиться в About, доступном из верхнего меню; альтернатива — официальный badge на публичной странице скачивания. Это вывод о лицензиях зависимостей, а не о доступности выплат или налогообложении.

## Сайт: рекомендация, без создания или публикации в этом изменении

Достаточно небольшой страницы RU/EN: описание, преимущества, настоящие скриншоты, ОС/архитектуры, установщик Windows и отдельные Mac ARM/Intel, версия/дата/контрольные суммы, GitHub/ошибки, лицензии/атрибуция Slint, изменения и добровольный Buy Me a Coffee. Одобренные установщики хранить в GitHub Releases и давать на них ссылки с сайта, а не класть бинарники в репозиторий исходников. Статическую страницу можно разместить на GitHub Pages. Сайт полезен для 1.0, но не обязателен для локального бета-тестирования. До отдельного разрешения публикации — только локальный/закрытый черновик, без публичной загрузки установщиков.

Проверены нативные светлая/RU и тёмная/EN при 800 × 640, кнопка настроек и системное меню «Справка», Tab/Shift-Tab внутри диалога, возврат фокуса кнопке About по Escape и внешний URL поддержки. Cmd+Q при открытом About начал корректное завершение. Unit/headless-регрессии прошли после RED. Полные локальные проверки, обзор, пакет и точный CI будут записаны после завершения.
