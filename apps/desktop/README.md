# FlowTorrent desktop

The shared Windows/macOS Rust and Slint package. Source, UI, tests, examples and platform packaging live here. The engine is still part of this package; no separate AppKit UI was imported.

Run Cargo commands from the [repository root](../../README.md); its workspace selects this package. Shared [assets](../../assets), [scripts](../../scripts), [vendor patches](../../vendor), Cargo.lock and the pinned toolchain stay at the root. See the [user guide](../../docs/user-guide.md) and [local Mac guide](../../docs/architecture/local-macos.md).
