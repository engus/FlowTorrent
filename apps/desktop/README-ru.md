# Настольный FlowTorrent

Общий Rust/Slint-пакет Windows/macOS. Здесь находятся исходники, UI, тесты, примеры и платформенная упаковка. Движок остаётся частью этого пакета; отдельный AppKit UI не импортирован.

Cargo запускается из [корня репозитория](../../README-ru.md), где workspace выбирает этот пакет. Общие [ресурсы](../../assets), [скрипты](../../scripts), [vendor-исправления](../../vendor), Cargo.lock и toolchain остаются в корне. См. [руководство пользователя](../../docs/user-guide-ru.md) и [сборку Mac](../../docs/architecture/local-macos.md).
