# Lucide control icons

Official source: https://github.com/lucide-icons/lucide, pinned revision `05232756c05e9ca7d5ad267e8694e9afa5d572fa`. Original static SVGs, full upstream ISC/Feather MIT license and SHA-256 inventory are included here. No icon font or runtime CDN dependency.

`ui/icons.slint` is the common control/status vocabulary. App and tray artwork remain separate FlowTorrent branding. Both package builders copy the complete license to `Lucide-LICENSE.txt` alongside the Nunito and project licenses.
