# Иконки управления Lucide

Официальный источник: https://github.com/lucide-icons/lucide, закреплённая версия `05232756c05e9ca7d5ad267e8694e9afa5d572fa`. Здесь исходные статические SVG, полная upstream-лицензия ISC/Feather MIT и инвентарь SHA-256. Шрифт иконок и CDN во время работы не используются.

`ui/icons.slint` задаёт единый набор управления/состояний. Изображения приложения и трея остаются отдельным брендингом FlowTorrent. Оба упаковщика копируют полную лицензию как `Lucide-LICENSE.txt` рядом с лицензиями Nunito и проекта.
