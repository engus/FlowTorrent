# FlowTorrent

Бесплатный BitTorrent-клиент для Windows и macOS без рекламы. Добавьте `.torrent` или magnet-ссылку, выберите файлы и папку, затем продолжайте загрузку и раздачу в фоне.

На обеих платформах используется общий интерфейс [Slint](https://slint.dev/), Rust и движок librqbit.

## Возможности

- Торренты и magnet-ссылки BitTorrent v1, включая гибридные метаданные с v1-хешем; просмотр состава и папки до начала загрузки.
- Пауза, продолжение, повторная попытка и восстановление сессии с проверкой данных перед возобновлением активных передач.
- Локальный поиск по названиям, сортировка и разделы «Все», «Загрузки», «Завершённые»; «Запустить все» и «Остановить все» действуют на весь список.
- Сворачиваемая боковая панель изменяемой ширины и нижняя панель сведений с прогрессом отдельных файлов и поиском.
- Передача в фоне, уведомления о завершении по выбору пользователя, скорости скачивания и отдачи и число скачиваемых торрентов в трее / строке меню.
- Удаление записи с сохранением файлов либо явный перенос принадлежащих приложению файлов в системную Корзину после подтверждения.
- Автосохранение настроек: системная, светлая или тёмная тема; системный язык или один из 14 языков; автозапуск; папка новых загрузок; уведомления и общие предустановки скорости.

Процент отдачи относится к текущей сессии движка, а не ко всему времени раздачи. Автоматической остановки по коэффициенту нет. Управление, безопасное удаление и восстановление описаны в [руководстве пользователя](docs/user-guide-ru.md).

## Состояние и установка

Текущая версия пакета — **0.1.0, тестовая сборка в разработке**. Публичного релиза 1.0 нет. Целевые системы исходного кода: Windows 10 22H2 / Windows 11 x64 и macOS 14 или новее на Apple Silicon и Intel. Этот список не означает прохождения всех физических приёмочных проверок.

Тестовый пакет Windows — **установщик Inno Setup для текущего пользователя**. На Mac откройте DMG нужной архитектуры и перетащите **FlowTorrent.app** в **Applications**; DMG служит контейнером распространения. Локальная сборка Mac также может создать `.app` напрямую. Тестовые сборки Windows не подписаны; Mac используют подпись ad-hoc без Developer ID и нотаризации. Данные для публичной подписи не предоставлены.

Подробности сборки и установки: [тестовые пакеты](docs/test-packages.md) и [локальная разработка Mac](docs/local-macos.md). Физические проверки Windows, настоящий DPI и экраны, покрытие поддерживаемых Mac, ночная работа и другие условия релиза остаются в [контрольном списке](docs/release-checklist.md). [Указатель документации](docs/README-ru.md) содержит исторические результаты CI и наблюдения на реальных системах; они не подтверждают более новую ревизию.

## Сборка из исходников

Установите Rust через rustup; `rust-toolchain.toml` закрепляет **Rust 1.92.0**. Для Windows нужны Visual Studio 2022 C++ Build Tools и Windows SDK, для macOS — Xcode Command Line Tools. Ограничивайте Cargo двумя задачами и используйте закреплённые зависимости.

Windows / PowerShell:

```powershell
cargo run --locked --release -j 2
```

macOS:

```sh
export MACOSX_DEPLOYMENT_TARGET=14.0
cargo run --locked --release -j 2
# Локальный пакет приложения с системной интеграцией:
./scripts/package-macos.sh
```

Проверки репозитория (на macOS сначала задайте deployment target, как выше):

```sh
cargo fmt --all -- --check
cargo clippy --locked --all-targets -j 2 -- -D warnings
cargo test --locked --all-targets -j 2
cargo build --locked --release -j 2
```

На macOS также выполните `cargo run --locked --example macos_lifecycle_probe -j 2`. Тесты используют управляемые локальные раздачи. Дополнительные инструменты упаковки и лицензий описаны в [руководстве по пакетам](docs/test-packages.md).
